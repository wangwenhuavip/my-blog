在VMware中搭建Windows 11环境用于学习，是熟悉系统或进行开发测试的绝佳方式。

整个过程主要分为三步：**获取镜像、配置虚拟机、安装系统**。



### 1. 获取Windows 11系统镜像 (ISO文件)

获取官方原版镜像最安全，主要有两种途径：

*   **官方渠道下载（推荐）**
    *   **方法一：直接下载ISO**：访问[Windows11微软官方下载页面](https://www.microsoft.com/software-download/windows11)，找到“**下载 Windows 11 磁盘映像 (ISO)**”部分，选择版本下载。
    *   **方法二：使用媒体创建工具**：在相同页面下载“**媒体创建工具**”，运行后选择“为另一台电脑创建安装介质”，工具会自动下载并生成ISO文件。

*   **其他可靠来源**
    *   一些知名科技网站会整理原版镜像的下载地址和校验信息（如SHA256值）。下载后务必**校验文件哈希值**，确保文件完整且未被篡改。

### 2. VMware虚拟机配置（关键步骤）

Windows 11对硬件有严格要求，需要在虚拟机中模拟支持，以下是核心配置：

| 配置项             | 要求                                       | 说明                                  |
| :----------------- | :----------------------------------------- | :------------------------------------ |
| **VMware版本**     | **Workstation 16.2.0 或更高版本**          | 低版本不支持vTPM 2.0                  |
| **客户机操作系统** | **Microsoft Windows** / **Windows 11 x64** | 创建虚拟机时选择                      |
| **固件类型**       | **UEFI**                                   | 必须使用UEFI，并**启用安全启动**      |
| **虚拟TPM (vTPM)** | **vTPM 2.0**                               | Windows 11的强制要求，必须添加        |
| **处理器**         | **2核及以上** 的64位CPU                    | 学习使用建议分配**4核**               |
| **内存**           | **最低4GB**                                | 为保证流畅，强烈建议分配**8GB或更多** |
| **硬盘**           | **最低64GB**                               | 建议分配**128GB或更大**的虚拟磁盘     |

**操作核心步骤（以VMware Workstation Pro为例）**：

1.  **新建虚拟机**：打开VMware，选择“创建新的虚拟机”。
2.  **选择镜像**：在安装来源中选择“**稍后安装操作系统**”。
3.  **选择系统**：客户机操作系统选“**Microsoft Windows**”，版本选“**Windows 11 x64**”。
4.  **配置硬件**：根据上表分配CPU核心数和内存大小。
5.  **关键：修改固件与加密**（这是最重要的步骤，90%的问题出在这里）：
    *   编辑虚拟机设置 → “**选项**” → “**高级**” → 将固件类型改为“**UEFI**”并**勾选“启用安全启动”**。
    *   转到“**选项**” → “**访问控制**” → 点击“**加密虚拟机**”并设置一个**牢记的密码**。
6.  **添加vTPM**：加密完成后，在“硬件”列表中点击“**添加**” → 选择“**受信任的平台模块**” → 完成。

### 3. 安装Windows 11系统

1.  **加载镜像**：在虚拟机设置中，将CD/DVD驱动器指向你下载的Windows 11 ISO文件。
2.  **启动安装**：开启虚拟机，按提示操作。在询问产品密钥时，选择“**我没有产品密钥**”。
3.  **选择版本**：根据需要选择Windows 11版本（如专业版、教育版等）。
4.  **安装类型**：选择“**自定义：仅安装Windows（高级）**”。
5.  **完成安装**：选择虚拟磁盘，点击“下一步”即可开始安装。

### 4. 后续优化与学习建议

*   **安装VMware Tools**：系统安装完成后，务必在VMware菜单栏点击“**虚拟机**” → “**安装VMware Tools**”。这能显著提升显示效果、鼠标流畅度及文件拖拽体验。
*   **善用快照功能**：在系统刚装好、或安装重要软件前，创建**快照**。这相当于一个“后悔药”，可以随时恢复到之前的状态，非常适合大胆地进行各种学习实验。
*   **网络模式选择**：
    *   **NAT模式**：虚拟机通过主机上网，适合大多数学习场景。
    *   **桥接模式**：虚拟机和主机在网络中地位平等，适合搭建服务器等需要独立IP的实验。
*   **关于激活**：你可以从微软官方购买正版授权。对于学习用途，微软也提供评估版或通过开发者计划获取试用。

### 5. 常见问题与排查

*   **“此电脑无法运行Windows 11”**：最常见的原因是**未启用vTPM 2.0**或**固件不是UEFI**。请严格按照第二节的步骤配置。
*   **安装时要求联网/微软账户**：这是新版本的强制要求。如果想跳过，可以在提示联网时，按 `Shift + F10` 打开命令提示符，输入 `OOBE\BYPASSNRO` 后回车，系统重启后即可选择“我没有Internet连接”。
*   **虚拟机运行卡顿**：尝试增加分配的内存和CPU核心数，并确保虚拟机文件存放在读写速度快的硬盘（如SSD）上。
